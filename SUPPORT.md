# Support

## Where to get help

- **Documentation**: [echelon.thepragmatik.dev](https://echelon.thepragmatik.dev)
- **Issues**: [GitHub Issues](https://github.com/thepragmatik/echelon/issues)
- **Discussions**: [GitHub Discussions](https://github.com/thepragmatik/echelon/discussions)
- **Discord**: Nous Research Discord — `#projects` channel

## Before asking

1. Check the [documentation](https://echelon.thepragmatik.dev)
2. Search [existing issues](https://github.com/thepragmatik/echelon/issues)
3. Run `scripts/dogfood.sh` to verify your setup
4. Review the FAQ and Troubleshooting pages (if available)

## Filing a good issue

- Include your environment: `uname -a`, `java -version`, `docker compose version`
- Include the full error output (not just summary)
- Include steps to reproduce from a fresh clone
